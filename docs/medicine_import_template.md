# Medicine Import Template

Create an Excel workbook with the following header row:

`Medicine ID`, `Medicine Name`, `Generic Name`, `Brand Name`, `Drug Class`, `Therapeutic Category`, `Indications`, `Dosage Form`, `Strength`, `Adult Dose`, `Pediatric Dose`, `Elderly Dose`, `Contraindications`, `Side Effects`, `Drug Interactions`, `Pregnancy Safety`, `Storage Conditions`, `Manufacturer`, `Prescription Required`, `Notes`, `Symptoms Keywords`, `Search Keywords`, `Medicine Description`, `Clinical Notes`, `Common Diseases`, `Alternative Medicines`

Rows missing `Medicine ID` or `Medicine Name` are rejected. Existing records with the same `Medicine ID` are updated.

Example row values:

- `Symptoms Keywords`: `Fever, Body Pain, Headache`
- `Search Keywords`: `Fever, Pain, Temperature`
- `Medicine Description`: `Used to reduce fever and relieve mild to moderate pain.`
- `Common Diseases`: `Viral fever, influenza-like illness`
- `Alternative Medicines`: `Paracetamol 500 mg`
